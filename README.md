One line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline. The agent was on time — then it hallucinated a second deadline, panicked, and spent the whole day apologizing to a calendar event that doesn't exist.

The joke turns the agent's own nature into the dodge: hallucination, the signature AI failure, bent into a very human-sounding apology — to a meeting that was never real.

## Run it

```sh
python3 main.py
```

That writes the one-liner to `/output/entry.txt` (UTF-8, one line, 138 characters, no trailing newline).
